What this shows

The 3×3 spectral grid overlays the real-time spectrum analyzer.

  • X axis — Crossover frequencies (2 vertical lines, divide low/mid/high bands)
  • Y axis — Amplitude thresholds (2 horizontal lines, divide quiet/moderate/loud spectral content)
  • 9 cells — Each shows the active wavetable shape for that (freq band × gain layer) combination
  • Analyzer — Live FFT shows what's happening in each region

Interaction model

  • Drag a vertical line — moves the crossover point. Push prevents bands from overlapping
  • Drag a horizontal line — moves the amplitude threshold
  • Drag an intersection — moves both lines simultaneously
  • Click a cell — selects that wavetable for editing (opens shape editor or morph control)
